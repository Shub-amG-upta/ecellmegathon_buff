# Recording script

**36 lines in 25 cases.** Read every line once in a quiet room. The 10 lines marked 🔊 are read again in a noisy room (list at the end).
How to set up, read and share: `eval/RECORDING.md`. Record with `eval/record_lines.sh <your name>`: it shows the same lines in the same order and names the files for you.

Each case is one conversation with the assistant. Lines in *italics* are what the assistant said before; you only say the **bold** lines. Some cases skip turns: only the turns we need are recorded.
